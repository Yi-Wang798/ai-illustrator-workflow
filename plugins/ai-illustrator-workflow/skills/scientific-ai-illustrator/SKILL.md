# AI Illustrator Reconstruction

Create layered `.ai` files with native paths, shapes, text, gradients, arrows, masks, effects, and groups. Treat an approved reference as measured geometry rather than loose inspiration.

## Bundled builder

- Use `../../scripts/sciai.py validate <spec.json>` to validate a structured drawing specification.
- Use `../../scripts/sciai.py build <spec.json> --output <stem>` to create Illustrator JSX without opening Illustrator.
- Add `--run` on Windows with `pywin32` installed to execute the JSX in Illustrator and save the native `.ai` plus PNG preview.
- Read [references/figure-spec.md](references/figure-spec.md) when creating or editing a structured specification.
- For a new simple row/column flow, use the spec's optional `layout`, `connections`, and text `container_id` fields. The builder computes aligned node positions, boundary endpoints, and optical label centers in one compilation pass. Do not auto-reflow a measured reference or force complex routes into this mode; use explicit measured paths instead.
- Every `--run` performs one actual Illustrator-document readback before final saving. Stable object IDs identify the new objects; actual types, names, layers, visibility, native counts, text/font, glyph bounds, and supported primitive bounds are checked. The report is written to `audits/<stem>.json` next to the build, and failures stop final AI/PNG export. Keep the report as the machine-readable part of the existing project audit, not a second manual checklist; move a passing report from the build directory into the permanent project audit directory before temporary cleanup. A rebuild creates a new document, so all its objects are new; for custom in-place edits, apply the same readback only to changed objects and their dependencies.

## Choose the mode

- Use concept mode when no user-approved composition exists. Read [references/concept-generation.md](references/concept-generation.md) before any image-generation call. Establish the one-sentence message, panel roles, scientific/evidence limits, and a fixed component dictionary. For multi-step processes, include entity states, source-domain colors, binding/containment relationships, retained/released parts, and entry-to-exit relationships. Resolve material ambiguities before rendering.
- Plan Illustrator construction before generation: every key entity needs a concrete primitive/operation/master recipe. For geometry-sensitive content, prepare an inspected native/vector scaffold as a reference input. Compile five separate composition prompts with `python scripts/concept_prompt.py <concept-contract.json>`; keep the content, states, and component identities fixed across alternatives. Journal-style requests use the reference's narrative and visual grammar, with restrained semantic color, clear hierarchy, credible geometry, and planned label/arrow space.
- Use the built-in image-generation tool by default, one call per distinct candidate. Use the newest quality-focused image capability available to the host, honor user-specified models, and report actual tool/model identity when exposed. Do not claim a specific model when the host hides it. Do not invent unsupported model-selection or batch arguments, and do not switch to an external API merely to improve style.
- Inspect every generated candidate for meaning, physical credibility, reconstructability, readability, and recurring-component consistency before showing it. A plausible-looking raster or a high aesthetic score is insufficient. Correct failed states and geometry before visual finish; use targeted edits and strengthen the scaffold when repeated repairs fail. Record visible defects and the native construction plan rather than claiming that prompt validation proves image correctness.
- Output the five candidates as five separate images rather than one combined contact sheet. Present them at equal visual weight, label them 1–5, and place one corresponding one-click selection control directly beneath or beside each candidate when the host exposes choice controls. Do not create the Illustrator project, trace geometry, or start reconstruction until the user's selection is received. If the host cannot render choice controls, fall back to five clearly numbered candidate cards and ask the user to reply with exactly one number. If none is accepted, generate five revised candidates from the feedback and repeat the same selection stage.
- If an approved reference already exists from the current or an earlier conversation, resume from it instead of regenerating candidates.
- Use underlay retrace mode whenever a target image exists. Read [references/underlay-reconstruction.md](references/underlay-reconstruction.md) before drawing.
- If the user asks to start again, create a new build/spec and output stem. Do not import coordinates, helper outputs, or objects from the rejected version.

## Underlay workflow and verification scope

Apply the following workflow in proportion to the requested work. For simple artwork, use direct construction and visual inspection; a separate worksheet, geometry contract, or audit manifest is not required unless a critical relationship needs it. For local edits, inspect only changed objects and their dependent constraints; reuse unchanged measurements and prior checks. For a new complex reconstruction, cover the full composition. These scope rules also govern the construction rules below and supporting references: their wording such as "every component" or "required pass" applies only within this scope. Preserve scientific meaning, native editability, and correctness of affected geometry.

1. Place the source image at its exact aspect ratio on `00_Reference`, above the background and below every vector layer. Lock it and keep it visible during construction.
2. Record source pixel dimensions and a uniform pixel-to-artboard transform. Express layout coordinates from source pixels rather than estimating directly in physical units.
3. Segment the complete composition into regions and give every region its own Illustrator layer. For every component record pixel bounds, primitives, topology, solid/gradient color model, gradient angle/stops when applicable, stroke role, text role, Illustrator construction method, and an observable acceptance feature.
4. Build a master registry before drawing. Every graphic that recurs without a topology or appearance change must have exactly one canonical master; all later occurrences must be instances of that master.
5. Create a machine-readable geometry contract only for relationships that affect scientific meaning or require precise geometric alignment. When a contract is needed, run `python scripts/geometry_preflight.py <contract.json>` and resolve failures in the affected constraints before constructing the affected components.
6. For complex reconstructions that need region tracking, maintain an audit manifest for the regions in scope. Resolve missing components and failed checks in that scope before export; do not require new audit entries for unchanged regions during a local edit.
7. Construct one component at a time over the underlay and compare it at component scale before approving it.
8. Calibrate regions sequentially. Show the reference and one region layer; hide every other drawing layer. Compare and correct translation, scale, rotation, line weight, local spacing, topology, and color/gradient mapping. Mark that region passed, then continue.
9. Export a preview and perform a full-composition pass for elements the user did not mention: spacing, clipping, overlaps, text clearance, counts, directions, alignment, topology, per-instance transforms, and color depth.
10. Hide `00_Reference` only for the clean export. Keep it locked inside the final `.ai` for later overlay inspection.

## Construction rules

- Build decomposable geometry from circles, ellipses, polygons, rectangles, rounded rectangles, and lines. Unite, intersect, or subtract parts with Shape Builder/Pathfinder, or emit the equivalent single final contour.
- Identify bilateral, radial, rotational, and point/central symmetry before placing individual points. Construct one canonical half/sector and reflect or rotate it from an exact axis/center; do not size the two ends independently. Declare every required axial or central symmetry with `mirror_symmetry`, including paired endpoints and primitive junctions, and reject any visually unequal end, thickness, curvature, or offset.
- Preserve primitive provenance for every regular composite. A nominal circle bounding box proves only a native ellipse/circle object; it must never be used to certify a freeform or composite path. Record the final path's actual anchor count, primitive junction coordinates, and any transition-anchor count in the geometry contract.
- For cylinders, lids, stacked rings, vessels, and other ellipse-based assemblies, fit one shared ellipse family first. Derive every related front/back arc, side endpoint, vertical drop, inset rim, and band depth from that family. Never draw the left and right ends or the upper and lower band curves independently. Declare each visible band with an `ellipse_band` check and reject unequal endpoint depth, nonshared centers/radii, or curves that miss their side endpoints.
- For a circular crown joined to two straight legs, use a circle/rectangle Shape Builder or Pathfinder construction, or the structured `open_circular_arch` object, then remove the unwanted closing segment. The final open contour must contain direct line-to-arc junctions and zero inserted transition anchors; reject any inward waist, hook, shoulder loop, or freehand connector between the primitives.
- Prefer Illustrator shape tools for any regular or partly regular component. Place the primitives first, then use anchor/direct selection to add or remove only the required segments, use Live Corners to convert required corners, and finish with Shape Builder/Pathfinder or deliberate overlap/covering. Do not redraw a regular silhouette freehand with many anchors.
- Fit regular geometry from source edge samples instead of sizing it by eye. Record the measured/fitted center, radius or axes, bounds, rotation, and residual in source pixels, then transform those parameters uniformly to the artboard. Refit when the isolated overlay shows systematic offset or scale error.
- Represent a required circle with an exact circle primitive or mathematically exact circular arc. Never approximate it with hand-tuned freeform Bézier handles. Represent a required straight line with a two-anchor straight path; never use Bézier handles on it.
- For parallel structures, generate every backbone and repeated connector from one measured axis, gap, and pitch. Numerically verify straightness, parallel gap, and endpoint alignment before rendering.
- Use the Pen/Curvature tool only for shapes that cannot be decomposed into regular geometry. Compare irregular paths at least twice at component scale.
- For irregular paths, use the fewest anchors that reproduce the silhouette. Put anchors at extrema, corners, and genuine inflection points; keep the two handles collinear at every smooth anchor. Reject accidental oscillations, flat spots, kinks, and extra inflection points even when the bounding box matches.
- Use Align, Distribute, Blend, Transform Again, symbols, patterns, or scripted repetition for repeated structures. Do not place repeated objects one by one by eye.
- For every recurring graphic whose internal structure and appearance do not change, construct one grouped master or Illustrator symbol and instantiate it everywhere else. Instances may change position and uniform scale; when the physical orientation requires it, rotate the complete instance as one group. Never redraw, restyle, edit anchors, change internal proportions, or alter stroke/color on individual instances.
- After duplicating a master, verify three Illustrator states before export: the intended target layer, the visible state of both the object and every ancestor, and the front/back stacking order relative to panel fills, clipping masks, and containers. A counted instance that is hidden or covered is a failed instance.
- When one entity has genuinely different states or topologies, define one canonical master per state, then reuse that state master everywhere it recurs. Do not confuse a state change with permission to redraw unchanged visual parts.
- Declare each master family with a `master_instances` geometry-contract check. Reject non-uniform scaling, geometry/style overrides, missing instances, or instances linked to a different master.
- Group the parts of every multi-part motif before translation, scaling, or rotation. Preserve the measured transform of each instance; do not force varied source objects into one uniform angle or size.
- Treat topology as a hard constraint. Adjacent, contained, connected, separated, masked, intersecting, and fused parts are not interchangeable.
- Treat visibility and occlusion as higher-level constraints than the local completeness of a rear object. Keep the rear object's source geometry regular/symmetric, draw it below the covering object, and clip or cover every hidden segment with the true front silhouette and final outline. Declare critical overlaps with `occlusion_stack`; never move, shorten asymmetrically, or expose a rear edge merely to keep both ends visibly complete.
- Treat every enclosing boundary as an ordered topology, not as a background shape. For circular insets, containers, windows, badges, frames, and similar motifs, clip/intersect all interior artwork to the enclosure (or emit equivalent final contours), then place one uninterrupted enclosure stroke above every interior object. Reject any interior fill or stroke that masks, breaks, doubles, or protrudes through the enclosing boundary.
- Compute every line, leader, graduation, seam, or interior stroke that must touch an enclosure from its exact intersection with the final boundary. Use an intentional underlap beneath a duplicate topmost outline when antialiasing could reveal a gap. Declare every such junction with a `boundary_attachment` check; reject fixed guessed endpoints, gaps, overshoot, or strokes drawn above the final outline.
- Assign every text object, symbol, motif, illustration, and arrow to an explicit container or to the unbounded artboard. For contained objects, calculate transformed visible bounds after scaling/rotation and require the full bounds to stay inside the container by the declared clearance. Reject boundary crossings, clipped tips, text protrusions, and near-tangent contact unless the brief explicitly defines an intentional crossing.
- Determine object-specific construction and acceptance gates from the current reference and store them in the project audit manifest. Never add a particular client's subject matter, product, mechanism, device, logo, or motif as a universal gate in this reusable skill.
- For complex assemblies, record the bounds and relationship of each subassembly before drawing the enclosing composition.
- Connect shapes by matching endpoint position and tangent direction. Use round caps/joins or Live Corners when the reference is rounded. When overlap is the cleanest construction, let one shape deliberately cover another or unite them with Shape Builder; reject near-misses, exposed seams, doubled edges, and crooked joins.
- Build constant-thickness loops, handles, frames, and rings from an outer primitive plus an offset/inner primitive, then compound/subtract them or emit the equivalent compound contour. Declare the visible sides with an `offset_ring` check. Apply highlights, shadows, and gradients after the geometry passes; never use shading to disguise uneven insets or broken tangency.
- Before adding depth cues, classify the requested representation as either `shaded_2d` or `actual_extrusion`. For `shaded_2d`, retain exactly one original silhouette and create all apparent volume with internal gradients, rim highlights, recess shadows, and clipped tonal regions; declare `shaded_2d_illusion` and forbid any offset duplicate that expands the outline. Use translated/offset depth faces and `translated_depth_copy` only when the reference actually depicts visible geometric extrusion. In either mode, keep one consistent light direction and validate the tonal hierarchy with `layered_3d_lighting` where applicable.
- Specular highlights on curved or tapered surfaces must follow the host surface's projected curvature, narrow/taper toward the ends where appropriate, use a soft falloff plus a restrained core, and be clipped by the same surface enclosure. Declare them with `specular_highlight`; reject a broad opaque white polygon, an arbitrary straight stripe on a curved object, or a highlight that contradicts the declared light direction.
- Build regular shadows, reflections, and connector patches from fitted ellipses/rectangles plus clipping or intersection whenever possible. A small soft patch is not permission to use an arbitrary asymmetric freehand blob.
- For a tapered vessel, capsule, cone, or similar body with a regular rounded base, construct the taper from straight primitive sides and the base from a standard circle/ellipse. Compute their exact tangent junctions, then unite them with Shape Builder/Pathfinder or emit the equivalent tangent contour. Declare the result with `tangent_circle_base`; reject a many-anchor hand-drawn bottom, a flattened arc, or any line-to-arc kink.
- For a skirt, collar, cap strip, or other band bounded by matching curved edges, duplicate the source ellipse/path and translate it by one exact depth, then crop both copies at shared side boundaries. Declare `parallel_ellipse_strip`; reject independently drawn upper and lower curves, unequal side drops, or a side edge protruding into the neighboring band.
- When a color, gradient, liquid, highlight, or shadow is intended to reach an enclosing outline, extend it beneath that outline and clip/intersect it with the exact enclosure source. Keep the duplicate final outline above it and declare `fill_boundary_underlap`. Reject white slits, parallel near-miss edges, or fills that merely stop close to the boundary.
- Trim hidden connectors, handles, hinges, and tabs to a narrow intentional underlap beneath their occluder. They must not span a visible seam or remain long enough to reappear through a gap. Declare the hidden endpoint with `occlusion_trim` and inspect every seam at component scale.

## Typography and strokes

- Default to Noto Sans SC for all text, using its regular/medium/bold weights for hierarchy. If the user explicitly specifies another font, use the user-specified family instead. Keep each semantic level internally consistent.
- Center text only when its role is centered. Use left/right alignment and leaders for external callouts when the composition requires them.
- For text inside a shape, never treat `TextFrame.visibleBounds` as the visible glyph boundary. Illustrator includes font ascender, descender, baseline, and line-metric whitespace in that value, which can report a mathematically centered text frame while the actual letters remain visibly high or low.
- Measure optical centering from the actual glyph contours: duplicate the editable text temporarily, call `createOutline()` on the duplicate, measure the outlined group's visible bounds, translate the original editable text to the target center, verify with a second outlined duplicate, then remove every temporary outline. Use `scripts/optical_text_center.jsxinc` or an equivalent implementation.
- Record the measured outlined-glyph center after placement and fail the geometry contract when it exceeds the project centering tolerance. A paragraph-center anchor, baseline position, text-frame bounds, or font-size-derived constant is never sufficient evidence.
- Define a project spacing scale and keep text clear of structural edges, symbols, illustrations, arrows, and neighboring labels. Reject collisions and ambiguous ownership.
- Use an explicit stroke hierarchy derived from the reference or style brief. Structural contours, normal lines, details, separators, and offset rims must have intentional relationships.
- Inspect united shapes for doubled edges, accidental seams, inconsistent caps/joins, and mis-scaled strokes.
- Inspect enclosing contours around their complete perimeter at component scale. A visually open or segmented frame fails even when its nominal ellipse/rectangle object still exists underneath other artwork.
- Build an arrow as one stroked path and set its start/end marker in Illustrator's Stroke panel whenever possible. Because Illustrator's scripting DOM does not expose Stroke-panel arrowheads, use an approved graphic style/action or perform that final panel operation in Illustrator. Never append a second stroked arrow object to the endpoint. If a separate geometric head is unavoidable, end the shaft exactly at the head base so no line protrudes through the tip. Verify cap, join, head alignment, and rounded bends at component scale.
- Put arrows on a dedicated layer above the objects they connect. For simple flows, compute endpoints from primitive boundaries and use explicit clearance; the automatic compiler rejects routes through unrelated node boxes and gaps too short for the head. For other routes, declare forbidden bounds and inspect collisions. Fail when an arrow is masked, clipped, overlapped, or lacks clearance.

## Color and appearance analysis

- Classify every component as solid, linear gradient, radial gradient, mesh/freeform gradient, pattern, texture, transparency, blend mode, clipping mask, or effect before construction.
- For gradients, record direction/angle, stop positions, colors, and stop opacity. Recreate detected gradients as native Illustrator appearances rather than replacing them with nearby flat colors.
- Sample colors from the approved reference or apply the supplied brand/color specification. Separate structural color, semantic color, highlight, shadow, and background roles.
- Reproduce depth cues only where the reference or brief uses them. Keep intentionally flat artwork flat.

## File lifecycle

- During one conversation/revision, write calibration previews, partial AI files, and draft exports only to a revision-specific temporary directory.
- After the final candidate passes all region and full-composition checks, promote exactly one `.ai` and one clean PNG as that revision's final deliverables, then delete that revision's temporary drafts and calibration images.
- On a later conversation, preserve the previous final deliverables and save the revised result as the next version. Delete only the new conversation's temporary drafts; never overwrite or delete the previous final.
- Treat cleanup as a blocking export gate, not optional housekeeping. Before handoff, run `python scripts/cleanup_revision.py <project-dir> <final-stem> --temp <revision-temp-dir>` and list every additional diagnostic or scratch artifact with `--artifact`. Do not claim completion while any revision work directory, calibration image, duplicate final export, failed AI document, or temporary diagnostic remains.
- After promotion, open or activate the `.ai` from the permanent `outputs` directory, then close every Illustrator document generated during that revision except that single final document. Close failed or untitled generated documents without saving; never close an unrelated user document.
- The permanent inventory for each revision is one versioned `.ai` plus one matching clean PNG. Preserve all earlier final pairs in `outputs`; keep reusable build specifications, geometry contracts, ledgers, and audit manifests outside revision temporary directories.
- Perform a final inventory check: all historical final pairs exist and are non-empty, the current revision temporary directory no longer exists, no diagnostic/scratch artifact from the revision remains, and Illustrator shows only the current revision final among documents created by the workflow.

## Verification and delivery

- Run schema validation and the geometry/project preflight checks required by the declared verification scope. Resolve failures in affected constraints before construction or export; do not require unrelated contracts for a simple local edit. Concept-contract validation checks inputs only, and never replaces inspection of generated pixels or the final Illustrator objects.
- Reuse the builder's actual-document report for checks it already covers; add only reference-specific relationships it cannot infer. Hidden-by-occlusion, scientific topology, arbitrary clipping contours, and final visual quality still need the scoped visual/geometry checks above. Do not treat layer visibility or object counts as proof that artwork is not covered.
- Open the generated `.ai` in Illustrator. Verify layer order, reference-layer lock/visibility, editable text, native paths/gradients/effects, groups, masks, and the clean preview.
- If Illustrator produces a corrupt preview or text-engine error, close only the generated documents, reopen a clean document, and regenerate. Never deliver a damaged export.
- Deliver the `.ai`, PNG preview, source spec/build file, and project audit manifest.

Store project-specific rules, assets, audits, drafts, and outputs in the user's project directory, not in this reusable plugin skill.
